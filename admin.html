📖 如何取得 GitHub Token（第一次使用才需要）
1. 登入 GitHub → 點右上角頭像 → Settings
2. 左側最底部 → Developer settings
3. Personal access tokens → Tokens (classic)
4. 點 Generate new token (classic)
5. Note 填：freight-updater
6. Expiration 選：1 year
7. 勾選權限：repo（整個大框打勾即可）
8. 點 Generate token
9. 複製出現的 token（只顯示一次！），貼到上方欄位
